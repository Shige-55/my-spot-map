## 開発・検証コマンド
Node.jsは22.13以降の22系、または24以降を使用してください（推奨24系）。第1段階で以下のスクリプトとlockfileを作成済みです。
```powershell
Set-Location -LiteralPath 'D:\CodexWork\MySpotMap'
npm.cmd ci
npm.cmd run dev
npm.cmd run lint
npm.cmd test
npm.cmd run build
npm.cmd run verify:dist
npm.cmd run preview
```
npm.cmd ciでpackage-lock.jsonどおりにインストールします。終了はCtrl+C。file://でindex.htmlを直接開かないでください。招待制版のbuild／previewのbaseは`/`へ変更しました。通常のdev／previewだけでは認証APIがないため、アプリの利用にはWorkerの環境が必要です。既存個人UIだけの隔離確認は`npm.cmd run dev -- --mode test-public`を使い、本番へそのモードを配信しないでください。APIを含めた手順はPRIVATE_DEPLOYMENT.mdを参照してください。verify:distは認証モード・資産・manifest・アイコン・余分なJSONを検査します。

PowerShellでnpm.ps1が実行ポリシーにより拒否される場合に対応し、Windows向けの手順はnpm.cmdと表記しています。実行ポリシーの変更は不要です。コマンドプロンプトや通常のnpmが使える環境ではnpmでも実行できます。Windows以外ではnpmに読み替えてください。

Windowsでnpm.cmd ciがVite／Rolldownのファイルを削除できずEPERMになる場合は、このプロジェクトのdev／previewを起動しているターミナルでCtrl+Cを押して終了し、再実行してください。地点DBやブラウザデータの削除は不要です。

npm.cmd testはVitest + fake-indexeddbの単体テストに続いて、ローカルViteサーバーを自動起動して画面テストを実行します。画面テストのOSMタイルはモックします。Windowsではインストール済みMicrosoft Edgeを利用します。他の環境では`npx playwright install chromium`を実行し、Chromiumを用意してください。WindowsでChromiumを選ぶ場合は`npx.cmd playwright install chromium`を実行し、PowerShellで`$env:PLAYWRIGHT_CHANNEL = 'chromium'`を設定してから実行します。ポート4173を使用するため、previewは終了してからテストしてください。個別実行は`npm.cmd run test:unit`、`npm.cmd run test:e2e`です。

第5段階からnpm.cmd testの最後にビルド版PWAテストも実行します。PWAだけを確認する場合は`npm.cmd run test:pwa`を使用してください。検証用の新旧ビルドは`.pwa-test/`へ生成し、4175と4176を使います。これらのポートも検証中は空けてください。生成物はGit・lint対象外で、通常のdistや利用者のDBは置換しません。

iPhone本番確認はHTTPSのPages URLで行い、Safariの共有メニューからホーム画面へ追加する。PCを停止しても配信はPages側で継続する。初期版の地点はPCと自動同期されず、JSONの手動移行が必要。
